II.   Program notes

What the orchestra learned.

We call this form a Convergence. Instead of repeating a theme between movements, the same gesture returns with a new musical ability. The score passes through five learning checkpoints before an original Classical-style finale. A symbolic model fits the note, rhythm, chord and interval choices; the form, orchestration and cadences are composed constraints.
